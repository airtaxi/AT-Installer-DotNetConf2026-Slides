구간왜 MSIX인가
쪽

자체 인스톨러는 모든 것을 직접 관리해야 했습니다

관리 대상직접 처리한 방법
설치 위치%AppData%\{InstallationFolderName}에 압축 해제
제거 정보HKCU\...\CurrentVersion\Uninstall에 직접 등록
설치한 파일 목록제거할 때 지우려고 InstalledFiles를 매니페스트에 따로 기록
스크립트설치 후, 재설치 후, 제거 시 실행할 스크립트를 각각 지원
제거 배치 파일유니코드 문자가 깨지는 문제로 UTF-8 인코딩 지정
그래도 앱이 실행 중에 AppData와 레지스트리에 남긴 흔적은 알 수 없습니다
구간왜 MSIX인가
쪽

이 발표에서 말하는 샌드박스는 파일과 레지스트리 가상화입니다

앱의 권한을 제한하는 AppContainer 격리와는 다릅니다. 그래도 설치와 제거를 관리하는 데는 가상화만으로 충분합니다.

AppData 쓰기패키지 전용 위치로 리디렉션
HKCU 쓰기패키지 전용 레지스트리로 리디렉션
제거운영체제가 리디렉션된 데이터까지 함께 삭제
설치 폴더읽기 전용으로 관리되어 앱이 덮어쓰지 못함
배포 단위.msixbundle 하나에 x64, x86, ARM64
대상 앱Electron, Tauri, WPF처럼 MSIX를 기본 제공하지 않는 앱도 포장

자체 인스톨러에서 InstalledFiles로 직접 추적하던 일을 이제 운영체제가 처리합니다.

public static bool IsRunningAsAdministrator()
{
    using var identity = WindowsIdentity.GetCurrent();
    return new WindowsPrincipal(identity).IsInRole(WindowsBuiltInRole.Administrator);
}

public static void RelaunchElevatedPreservingArguments()
{
    var arguments = string.Join(' ', Environment.GetCommandLineArgs().Skip(1)
        .Select(arg => arg.Contains(' ') ? $"\"{arg}\"" : arg));
    if (!arguments.Contains("/install", StringComparison.Ordinal)) arguments += " /install";

    try { Process.Start(new ProcessStartInfo { FileName = Environment.ProcessPath, Arguments = arguments,
                                           Verb = "runas", UseShellExecute = true }); }
    catch { }
    Environment.Exit(0);
}

Installer/Msix/MsixDeploymentHelper.cs
public static async Task<MsixDeploymentResult> AddPackageAsync(string packageFilePath, IProgress<DeploymentProgress> progress)
{
    var packageManager = new PackageManager();
    var packageUri = new Uri(packageFilePath);
    var deploymentOperation = packageManager.AddPackageAsync(packageUri, null, DeploymentOptions.ForceApplicationShutdown);

    try { await deploymentOperation.AsTask(progress); }
    catch (Exception exception)
    {
        return new MsixDeploymentResult { IsSuccessful = false, ErrorText = exception.Message, ... };
    }

    // 완료 상태와 오류 코드를 MsixDeploymentResult로 정리해 반환
}
ForceApplicationShutdown실행 중인 이전 버전을 종료하고 업데이트
AsTask(progress)WinRT 진행률을 IProgress<T>로 받아 진행률 막대에 연결

stream.Seek(PeOffsetLocation, SeekOrigin.Begin);  // 0x3C
var peOffset = reader.ReadInt32();

stream.Seek(peOffset, SeekOrigin.Begin);
var peSignature = reader.ReadUInt32();
if (peSignature != PeSignature) return "Unknown";

var machine = reader.ReadUInt16();
return machine switch
{
    0x8664 => "x64",
    0x014C => "x86",
    0xAA64 => "ARM64",
